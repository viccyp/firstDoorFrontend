# 🚪 firstDoor Frontend

## Welcome to firstDoor!

firstDoor is a job search application designed to help users discover entry-level opportunities, explore job details, and keep track of interesting roles and job applications, all in one place.

This repository contains the frontend application built using **Blazor**.

---

## ✨ Features

* Browse available job opportunities
* View detailed information about each role
* Save jobs for future reference and application
* Navigate between Jobs and Saved Jobs pages

---

## 🏗️✨ Upcoming Features

* Search for jobs by keyword
* Dedicated login page and user accounts
* Filter and sort job listings

---

## 🛠️ Technologies Used

* .NET 8
* Blazor
* Razor Components
* C#
* HTML & CSS

---

## 🚀 Getting Started

### Prerequisites

Before running the project, make sure you have:

* .NET 8 SDK installed
* Visual Studio 2022 (recommended)

### Running the Frontend

1. Clone the repository.
2. Navigate to the frontend project directory.
3. Run the application:

```bash
dotnet watch run
```

or

```bash
dotnet run
```

4. Open the URL displayed in your terminal.

---

## 🔗 Backend Connection

The frontend communicates with the firstDoor backend API.

For full functionality, including job searches and saving jobs, ensure the backend application is running before starting the frontend.

**Backend repository:**  [Click Here](https://github.com/EthanBerry638/firstDoorBackEnd.git)
